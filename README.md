# 🌦️ Weather App & 🔐 Password Generator - React Projects

This repository contains two React-based projects:

1. **Weather App** – Search for any city and get real-time weather data including temperature, humidity, and description using a weather API.
2. **Password Generator** – Create secure, customizable passwords with options for length, characters, and easy copy-to-clipboard functionality.

---

## 🚀 Features

### Weather App
- Real-time weather data via API (e.g., OpenWeatherMap)
- City search functionality
- Responsive UI design
- Error handling for invalid locations

### Password Generator
- Adjustable password length
- Toggle character types (uppercase, numeber , symbols)
- Copy to clipboard
- Instant feedback
